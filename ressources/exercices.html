Exercices supplémentaires

Des exercices courts pour chaque balise vue en cours, rangés par séance. Ils complètent les exercices de fin de séance, si vous voulez vous entraîner davantage — 139 exercices au total.

Comment ça marche

  • Dans chaque code, remplacez les ____ par ce qui manque. Certains exercices demandent plutôt de corriger une erreur.
  • Écrivez votre réponse dans VS Code et testez-la avec Live Server, puis ouvrez la correction pour comparer.
  • Rien à rendre : ces exercices sont entièrement libres. Les seuls travaux à déposer dans Teams sont ceux des séances 2, 4 et 6.
  • Choisissez la séance que vous venez de suivre dans le sommaire : vous n'y trouverez que des balises déjà vues.

Séance 1 — Le Web et le HTML

17 exercices sur les balises de la séance 1. Les exercices de fin de séance, plus complets, sont dans la partie Exercices de la séance 1.

Le squelette d'une page

1.1 — <!DOCTYPE html>

Complétez la toute première ligne d'une page HTML5.

____
<html lang="fr">
Voir la correction 
<!DOCTYPE html>
<html lang="fr">

Cette déclaration annonce au navigateur qu'il s'agit d'une page HTML5. Elle est toujours en première ligne.

1.2 — <html lang>

Indiquez que le contenu de la page est en français.

<html ____="fr">
Voir la correction 
<html lang="fr">

lang sert aux lecteurs d'écran (pour la prononciation) et aux moteurs de recherche.

1.3 — <head> et <body>

Complétez avec les deux grandes parties de la page : l'une invisible, l'autre visible.

<html lang="fr">
<____>
  <title>Mon site</title>
</____>
<____>
  <h1>Bienvenue</h1>
</____>
</html>
Voir la correction 
<html lang="fr">
<head>
  <title>Mon site</title>
</head>
<body>
  <h1>Bienvenue</h1>
</body>
</html>

Le <head> contient les informations sur la page (invisibles), le <body> tout ce qui s'affiche.

1.4 — <meta charset>

Complétez pour que les accents s'affichent correctement.

<meta ____="____">
Voir la correction 
<meta charset="UTF-8">

UTF-8 est l'encodage qui contient tous les caractères, accents compris.

1.5 — <title>

Le texte « Ma page » doit apparaître dans l'onglet du navigateur.

<head>
  <meta charset="UTF-8">
  <____>Ma page</____>
</head>
Voir la correction 
<head>
  <meta charset="UTF-8">
  <title>Ma page</title>
</head>

Le titre ne s'affiche pas dans la page, mais dans l'onglet, les favoris et les résultats de recherche.

1.6 — <link>

Reliez la page à la feuille de style css/style.css.

<link rel="____" href="____">
Voir la correction 
<link rel="stylesheet" href="css/style.css">

rel dit le type de ressource (une feuille de style), href où la trouver.

Le texte

1.7 — <h1> à <h6>

« Le Japon » est le titre principal de la page, « La géographie » une grande partie.

<____>Le Japon</____>
<____>La géographie</____>
Voir la correction 
<h1>Le Japon</h1>
<h2>La géographie</h2>

Un seul <h1> par page, puis <h2> pour les grandes parties.

1.8 — <p>

Transformez ces deux phrases en deux paragraphes séparés.

Le Japon compte plus de 6800 îles.
Sa capitale est Tokyo.
Voir la correction 
<p>Le Japon compte plus de 6800 îles.</p>
<p>Sa capitale est Tokyo.</p>

Un retour à la ligne dans le code ne suffit pas : le navigateur l'ignore. Chaque bloc de texte va dans son <p>.

1.9 — <br>

Affichez l'adresse sur deux lignes, dans un seul paragraphe.

<p>Rue de l'Exemple 12____1140 Evere</p>
Voir la correction 
<p>Rue de l'Exemple 12<br>1140 Evere</p>

<br> est une balise orpheline : un retour à la ligne à l'intérieur d'un paragraphe (adresse, poème).

1.10 — <hr>

Séparez les deux thèmes par une rupture thématique.

<p>Fin de la partie sur le climat.</p>
____
<p>Passons à la cuisine.</p>
Voir la correction 
<p>Fin de la partie sur le climat.</p>
<hr>
<p>Passons à la cuisine.</p>

<hr> marque un changement de sujet. Le navigateur l'affiche comme une ligne horizontale.

1.11 — L'imbrication

Corrigez l'ordre de fermeture des balises.

<p><strong><em>Attention</strong></em></p>
Voir la correction 
<p><strong><em>Attention</em></strong></p>

La dernière balise ouverte est la première fermée, comme des poupées russes.

1.12 — Les commentaires <!-- -->

Transformez la note en commentaire, pour qu'elle ne s'affiche pas.

____ Partie à terminer ____
Voir la correction 
<!-- Partie à terminer -->

Un commentaire est ignoré par le navigateur, mais reste lisible dans le code (F12).

1.13 — Les entités

Complétez pour afficher : « La balise <p> » et « Tom & Jerry ».

<p>La balise ____p____</p>
<p>Tom ____ Jerry</p>
Voir la correction 
<p>La balise &lt;p&gt;</p>
<p>Tom &amp; Jerry</p>

&lt;, &gt; et &amp; affichent les caractères réservés du HTML.

Images et liens

1.14 — <img>

Affichez l'image images/chat.jpg, qui montre un chat roux endormi.

<img ____="images/chat.jpg" ____="Un chat roux endormi">
Voir la correction 
<img src="images/chat.jpg" alt="Un chat roux endormi">

src indique le fichier, alt le décrit pour ceux qui ne voient pas l'image.

1.15 — <a>

Faites du texte « Contact » un lien vers contact.html.

<a ____="contact.html">Contact</a>
Voir la correction 
<a href="contact.html">Contact</a>

href (hypertext reference) contient la destination du lien.

1.16 — Chemin relatif

Vous êtes dans pages/contact.html. Affichez images/logo.png (le dossier images/ est à la racine).

<img src="____" alt="Logo du site">
Voir la correction 
<img src="../images/logo.png" alt="Logo du site">

../ remonte d'un dossier : de pages/ vers la racine, puis on redescend dans images/.

1.17 — Chemin absolu

Créez un lien vers le site du W3C, à l'adresse www.w3.org.

<a href="____">Le W3C</a>
Voir la correction 
<a href="https://www.w3.org">Le W3C</a>

Pour un autre site, l'adresse complète commence par https://. Sans elle, le navigateur chercherait un fichier dans votre site.

Séance 2 — Mise en place

17 exercices sur les balises de la séance 2. Les exercices de fin de séance, plus complets, sont dans la partie Exercices de la séance 2.

Titres et paragraphes

2.1 — Hiérarchie des titres

Corrigez le niveau du deuxième titre.

<h1>Mes recettes</h1>
<h3>Les crêpes</h3>
Voir la correction 
<h1>Mes recettes</h1>
<h2>Les crêpes</h2>

Pas de saut de niveau : après un <h1> vient un <h2>.

2.2 — Espaces et retours à la ligne

Combien de lignes ce code affiche-t-il dans le navigateur ? Corrigez-le pour obtenir deux paragraphes.

<p>Première idée.


Deuxième idée.</p>
Voir la correction 
<p>Première idée.</p>
<p>Deuxième idée.</p>

Le navigateur remplace les retours à la ligne et les espaces multiples par un seul espace : le code d'origine affiche une seule ligne.

Les listes

2.3 — <ul> et <li>

Créez une liste à puces des ingrédients.

<____>
  <____>Farine</____>
  <____>Œufs</____>
  <____>Lait</____>
</____>
Voir la correction 
<ul>
  <li>Farine</li>
  <li>Œufs</li>
  <li>Lait</li>
</ul>

<ul> pour une liste sans ordre, un <li> par élément.

2.4 — <ol>

Ces étapes doivent être suivies dans l'ordre : complétez.

<____>
  <li>Allumer l'ordinateur</li>
  <li>Ouvrir VS Code</li>
  <li>Créer le fichier index.html</li>
</____>
Voir la correction 
<ol>
  <li>Allumer l'ordinateur</li>
  <li>Ouvrir VS Code</li>
  <li>Créer le fichier index.html</li>
</ol>

<ol> numérote automatiquement : l'ordre a du sens.

2.5 — Liste imbriquée

Placez la sous-liste « Sucre, Chocolat » sous « Crêpes sucrées », au bon endroit.

<ul>
  <li>Crêpes sucrées</li>
  ____
  <li>Galettes salées</li>
</ul>
Voir la correction 
<ul>
  <li>Crêpes sucrées
    <ul>
      <li>Sucre</li>
      <li>Chocolat</li>
    </ul>
  </li>
  <li>Galettes salées</li>
</ul>

La sous-liste va dans le <li> parent, avant son </li> : il faut donc déplacer cette balise fermante.

2.6 — <dl>, <dt>, <dd>

Complétez la liste de description.

<dl>
  <____>HTML</____>
  <____>Le langage qui structure une page.</____>
</dl>
Voir la correction 
<dl>
  <dt>HTML</dt>
  <dd>Le langage qui structure une page.</dd>
</dl>

<dt> pour le terme, <dd> pour sa description.

La mise en emphase

2.7 — <strong>

« Ne pas dépasser 180 °C » est un avertissement important.

<p><____>Ne pas dépasser 180 °C.</____></p>
Voir la correction 
<p><strong>Ne pas dépasser 180 °C.</strong></p>

<strong> = importance forte. Affiché en gras par défaut.

2.8 — <em>

On insiste sur « jamais », comme à l'oral.

<p>Je n'ai <____>jamais</____> dit ça.</p>
Voir la correction 
<p>Je n'ai <em>jamais</em> dit ça.</p>

<em> = accent d'insistance. Affiché en italique par défaut.

2.9 — <i>

« Felis catus » est le nom latin du chat : un terme dans une autre langue.

<p>Le chat (<____>Felis catus</____>) est un mammifère.</p>
Voir la correction 
<p>Le chat (<i>Felis catus</i>) est un mammifère.</p>

<i> = un ton différent, sans insistance : mot étranger, terme technique.

2.10 — <b>

Faites ressortir le mot-clé « sarrasin », sans qu'il soit plus important que le reste.

<p>La galette se fait avec de la farine de <____>sarrasin</____>.</p>
Voir la correction 
<p>La galette se fait avec de la farine de <b>sarrasin</b>.</p>

<b> attire l'attention sans notion d'importance (contrairement à <strong>).

2.11 — <s>

Barrez l'ancien prix, qui n'est plus valable.

<p>Prix : <____>8 €</____> 6 €</p>
Voir la correction 
<p>Prix : <s>8 €</s> 6 €</p>

<s> marque une information qui n'est plus exacte.

2.12 — Pourquoi éviter <u>

Remplacez la balise par celle qui convient pour un mot sur lequel on insiste.

<p>Rendez le travail <u>avant</u> vendredi.</p>
Voir la correction 
<p>Rendez le travail <em>avant</em> vendredi.</p>

Un texte souligné ressemble à un lien sur le Web. Pour insister, on utilise <em> (ou <strong> si c'est important).

Citer et montrer du code

2.13 — <blockquote>

Faites de ce texte une citation en bloc, avec la source https://exemple.be.

<____ ____="https://exemple.be">
  <p>Le Web appartient à tout le monde.</p>
</____>
Voir la correction 
<blockquote cite="https://exemple.be">
  <p>Le Web appartient à tout le monde.</p>
</blockquote>

<blockquote> pour une citation longue, cite pour sa source.

2.14 — <code>

Présentez index.html comme du code dans la phrase.

<p>La page d'accueil s'appelle toujours <____>index.html</____>.</p>
Voir la correction 
<p>La page d'accueil s'appelle toujours <code>index.html</code>.</p>

<code> affiche un nom de fichier ou un bout de code avec une police à chasse fixe.

2.15 — <pre>

Ce bloc doit garder ses retours à la ligne et ses espaces.

<____>mon-site/
├── index.html
└── images/</____>
Voir la correction 
<pre>mon-site/
├── index.html
└── images/</pre>

<pre> (préformaté) conserve les espaces et les retours à la ligne du code.

Les images

2.16 — Un bon alt

Remplacez l'alt par une vraie description de la photo (une tour Eiffel sous la neige).

<img src="images/paris.jpg" alt="photo">
Voir la correction 
<img src="images/paris.jpg" alt="La tour Eiffel sous la neige">

« photo » ou « image » ne décrit rien. L'alt dit ce que l'image montre.

2.17 — width et height

Affichez l'image en 300 × 200 pixels.

<img src="images/paris.jpg" alt="La tour Eiffel sous la neige" ____="300" ____="200">
Voir la correction 
<img src="images/paris.jpg" alt="La tour Eiffel sous la neige" width="300" height="200">

Les valeurs sont en pixels, sans unité. Le navigateur réserve la place avant même que l'image soit chargée.

Séance 3 — HTML avancé

36 exercices sur les balises de la séance 3. Les exercices de fin de séance, plus complets, sont dans la partie Exercices de la séance 3.

Le head, les icônes et class

3.1 — Le favicon

Affichez icons/favicon.png dans l'onglet du navigateur.

<link rel="____" type="image/png" href="____">
Voir la correction 
<link rel="icon" type="image/png" href="icons/favicon.png">

rel="icon" indique que le fichier est le favicon.

3.2 — Une icône Font Awesome

Font Awesome est relié dans le <head>. Affichez l'icône pleine (solid) d'une enveloppe devant le texte, cachée aux lecteurs d'écran.

<p><i class="____ ____" ____="true"></i> Nous écrire</p>
Voir la correction 
<p><i class="fa-solid fa-envelope" aria-hidden="true"></i> Nous écrire</p>

Deux classes : le style (fa-solid) et le nom de l'icône (fa-envelope). aria-hidden : le texte suffit.

3.3 — L'attribut class

Donnez la même étiquette promo aux deux premiers paragraphes.

<p ____="promo">Crêpe du mois : -20 %</p>
<p ____="promo">Menu enfant offert</p>
<p>Ouvert du mardi au dimanche.</p>
Voir la correction 
<p class="promo">Crêpe du mois : -20 %</p>
<p class="promo">Menu enfant offert</p>
<p>Ouvert du mardi au dimanche.</p>

Une même classe peut se répéter (contrairement à un id). Le CSS s'en servira en séance 5.

Les balises sémantiques

3.4 — <header> et <nav>

Complétez : l'en-tête de la page contient le menu principal.

<____>
  <h1>La Crêperie</h1>
  <____>
    <ul>
      <li><a href="index.html">Accueil</a></li>
      <li><a href="carte.html">La carte</a></li>
    </ul>
  </____>
</____>
Voir la correction 
<header>
  <h1>La Crêperie</h1>
  <nav>
    <ul>
      <li><a href="index.html">Accueil</a></li>
      <li><a href="carte.html">La carte</a></li>
    </ul>
  </nav>
</header>

<header> = l'en-tête ; <nav> = le bloc de navigation principal.

3.5 — <main>

Englobez le contenu propre à cette page.

<header>...</header>
<____>
  <h2>Bienvenue</h2>
  <p>Installez-vous !</p>
</____>
<footer>...</footer>
Voir la correction 
<header>...</header>
<main>
  <h2>Bienvenue</h2>
  <p>Installez-vous !</p>
</main>
<footer>...</footer>

Un seul <main> par page, entre l'en-tête et le pied de page.

3.6 — <section> et <article>

Une rubrique « Actualités » contient une actualité autonome. Complétez.

<____>
  <h2>Actualités</h2>
  <____>
    <h3>Nouvelle crêpe du mois</h3>
    <p>La pomme-caramel arrive !</p>
  </____>
</____>
Voir la correction 
<section>
  <h2>Actualités</h2>
  <article>
    <h3>Nouvelle crêpe du mois</h3>
    <p>La pomme-caramel arrive !</p>
  </article>
</section>

La rubrique (un thème avec son titre) est une <section> ; l'actualité, qui a du sens seule, un <article>.

3.7 — <aside>

Cet encadré est lié au contenu, mais secondaire.

<____>
  <h3>Le saviez-vous ?</h3>
  <p>La Chandeleur se fête le 2 février.</p>
</____>
Voir la correction 
<aside>
  <h3>Le saviez-vous ?</h3>
  <p>La Chandeleur se fête le 2 février.</p>
</aside>

<aside> : si on le supprime, la page reste compréhensible.

3.8 — <footer>

Complétez le pied de page.

<____>
  <p>&copy; 2026 La Crêperie</p>
  <a href="mentions-legales.html">Mentions légales</a>
</____>
Voir la correction 
<footer>
  <p>&copy; 2026 La Crêperie</p>
  <a href="mentions-legales.html">Mentions légales</a>
</footer>

<footer> : copyright, contact, mentions légales.

Les hyperliens

3.9 — Une ancre

Le lien doit faire défiler la page jusqu'au titre « Horaires ».

<a href="____">Voir les horaires</a>

<h2 ____="horaires">Horaires</h2>
Voir la correction 
<a href="#horaires">Voir les horaires</a>

<h2 id="horaires">Horaires</h2>

# suivi de l'id de l'élément ciblé.

3.10 — Section d'une autre page

Le lien doit ouvrir contact.html directement à la section id="plan".

<a href="____">Voir le plan d'accès</a>
Voir la correction 
<a href="contact.html#plan">Voir le plan d'accès</a>

Le chemin de la page, puis # et l'id.

3.11 — Lien externe dans un nouvel onglet

Ouvrez Wikipédia dans un nouvel onglet, de façon sécurisée.

<a href="https://fr.wikipedia.org" target="____" rel="____">Wikipédia</a>
Voir la correction 
<a href="https://fr.wikipedia.org" target="_blank" rel="noopener noreferrer">Wikipédia</a>

target="_blank" va toujours avec rel="noopener noreferrer".

3.12 — mailto: et tel:

Le premier lien ouvre la messagerie, le second lance un appel.

<a href="____contact@exemple.be">Nous écrire</a>
<a href="____+3221234567">Nous appeler</a>
Voir la correction 
<a href="mailto:contact@exemple.be">Nous écrire</a>
<a href="tel:+3221234567">Nous appeler</a>

mailto: pour un e-mail, tel: pour un numéro (pratique sur smartphone).

3.13 — download

Proposez d'enregistrer le PDF plutôt que de l'ouvrir.

<a href="documents/carte.pdf" ____>Télécharger la carte (PDF, 1 Mo)</a>
Voir la correction 
<a href="documents/carte.pdf" download>Télécharger la carte (PDF, 1 Mo)</a>

download s'écrit sans valeur.

3.14 — Une image cliquable

Rendez le logo cliquable vers l'accueil.

____
  <img src="images/logo.png" alt="La Crêperie — accueil">
____
Voir la correction 
<a href="index.html">
  <img src="images/logo.png" alt="La Crêperie — accueil">
</a>

L'image se place dans le <a>. Son alt décrit la destination.

Les médias

3.15 — <video>

Affichez la vidéo avec ses commandes de lecture.

<video ____ width="400">
  <source src="videos/demo.mp4" type="____">
</video>
Voir la correction 
<video controls width="400">
  <source src="videos/demo.mp4" type="video/mp4">
</video>

Sans controls, aucun bouton de lecture n'apparaît.

3.16 — L'attribut poster

Affichez images/apercu.jpg avant le lancement de la vidéo.

<video controls ____="images/apercu.jpg">
  <source src="videos/demo.mp4" type="video/mp4">
</video>
Voir la correction 
<video controls poster="images/apercu.jpg">
  <source src="videos/demo.mp4" type="video/mp4">
</video>

poster : l'image d'attente.

3.17 — <audio>

Insérez le fichier son avec ses commandes.

<____ controls>
  <source src="audio/bienvenue.mp3" type="audio/mpeg">
</____>
Voir la correction 
<audio controls>
  <source src="audio/bienvenue.mp3" type="audio/mpeg">
</audio>

Même principe que <video>. Le type d'un MP3 est audio/mpeg.

3.18 — <track>

Ajoutez les sous-titres français videos/demo-fr.vtt.

<video controls>
  <source src="videos/demo.mp4" type="video/mp4">
  <____ src="videos/demo-fr.vtt" kind="subtitles" srclang="fr" label="Français">
</video>
Voir la correction 
<video controls>
  <source src="videos/demo.mp4" type="video/mp4">
  <track src="videos/demo-fr.vtt" kind="subtitles" srclang="fr" label="Français">
</video>

<track> se place après les <source>. Les sous-titres sont dans un fichier .vtt.

3.19 — <iframe>

Affichez le PDF directement dans la page, avec un titre accessible.

<____ src="documents/carte.pdf" width="500" height="300" title="Carte de la crêperie"></____>
Voir la correction 
<iframe src="documents/carte.pdf" width="500" height="300" title="Carte de la crêperie"></iframe>

<iframe> affiche un autre document dans la page (PDF, vidéo YouTube...).

Les tableaux

3.20 — <table>, <tr>, <td>

Complétez ce tableau d'une ligne et deux cellules.

<____>
  <____>
    <____>Lundi</____>
    <____>9h – 18h</____>
  </____>
</____>
Voir la correction 
<table>
  <tr>
    <td>Lundi</td>
    <td>9h – 18h</td>
  </tr>
</table>

<table> contient des lignes <tr>, qui contiennent des cellules <td>.

3.21 — <caption>

Donnez le titre « Horaires d'ouverture » au tableau.

<table>
  <____>Horaires d'ouverture</____>
  ...
</table>
Voir la correction 
<table>
  <caption>Horaires d'ouverture</caption>
  ...
</table>

<caption> se place juste après <table>.

3.22 — <thead> et <tbody>

Séparez la ligne d'en-tête des lignes de données.

<table>
  <____>
    <tr><th scope="col">Jour</th><th scope="col">Horaires</th></tr>
  </____>
  <____>
    <tr><td>Lundi</td><td>9h – 18h</td></tr>
  </____>
</table>
Voir la correction 
<table>
  <thead>
    <tr><th scope="col">Jour</th><th scope="col">Horaires</th></tr>
  </thead>
  <tbody>
    <tr><td>Lundi</td><td>9h – 18h</td></tr>
  </tbody>
</table>

<thead> pour l'en-tête, <tbody> pour les données.

3.23 — <th> et scope

« Jour » est l'en-tête d'une colonne, « Lundi » l'en-tête d'une ligne.

<tr><____ scope="____">Jour</____><th scope="col">Horaires</th></tr>
<tr><____ scope="____">Lundi</____><td>9h – 18h</td></tr>
Voir la correction 
<tr><th scope="col">Jour</th><th scope="col">Horaires</th></tr>
<tr><th scope="row">Lundi</th><td>9h – 18h</td></tr>

scope="col" pour une colonne, scope="row" pour une ligne.

3.24 — colspan

La cellule « Fermé » doit s'étendre sur les deux colonnes d'horaires.

<tr>
  <th scope="row">Dimanche</th>
  <td ____="2">Fermé</td>
</tr>
Voir la correction 
<tr>
  <th scope="row">Dimanche</th>
  <td colspan="2">Fermé</td>
</tr>

colspan fusionne des cellules horizontalement.

3.25 — rowspan

La cellule « Lundi » doit couvrir deux lignes. Supprimez aussi ce qui est en trop.

<tr><th scope="rowgroup">Lundi</th><td>Matin</td></tr>
<tr><th>Lundi</th><td>Après-midi</td></tr>
Voir la correction 
<tr><th rowspan="2" scope="rowgroup">Lundi</th><td>Matin</td></tr>
<tr><td>Après-midi</td></tr>

Avec rowspan="2", la cellule ne doit plus être répétée sur la ligne suivante.

Les formulaires

3.26 — <form>

Les données doivent être envoyées à /contact, sans apparaître dans l'URL.

<form action="____" method="____">
  ...
</form>
Voir la correction 
<form action="/contact" method="post">
  ...
</form>

action = où envoyer ; method="post" = dans le corps de la requête, pas dans l'URL.

3.27 — <label>

Reliez l'étiquette au champ.

<label ____="ville">Votre ville</label>
<input type="text" ____="ville" name="ville">
Voir la correction 
<label for="ville">Votre ville</label>
<input type="text" id="ville" name="ville">

for du label = id du champ. Cliquer sur l'étiquette active alors le champ.

3.28 — L'attribut name

Sans cet attribut, la donnée ne serait pas envoyée. Complétez.

<input type="text" id="prenom" ____="prenom">
Voir la correction 
<input type="text" id="prenom" name="prenom">

name est le nom de la donnée envoyée au serveur : prenom=Alice.

3.29 — type="email" et required

Le navigateur doit vérifier le format de l'adresse, et le champ est obligatoire.

<input type="____" id="email" name="email" ____>
Voir la correction 
<input type="email" id="email" name="email" required>

type="email" vérifie la présence d'un @ ; required bloque l'envoi si le champ est vide.

3.30 — Le bon type

Choisissez le bon type pour chaque champ : mot de passe, nombre de personnes, date, téléphone.

<input type="____" name="mdp">
<input type="____" name="personnes" min="1" max="12">
<input type="____" name="jour">
<input type="____" name="telephone">
Voir la correction 
<input type="password" name="mdp">
<input type="number" name="personnes" min="1" max="12">
<input type="date" name="jour">
<input type="tel" name="telephone">

Chaque type change le comportement du champ : caractères masqués, flèches, calendrier, clavier numérique sur smartphone.

3.31 — type="radio"

Un seul choix possible entre « Midi » et « Soir ». Complétez.

<input type="radio" id="midi" name="____" value="midi" ____>
<label for="midi">Midi</label>
<input type="radio" id="soir" name="____" value="soir">
<label for="soir">Soir</label>
Voir la correction 
<input type="radio" id="midi" name="service" value="midi" checked>
<label for="midi">Midi</label>
<input type="radio" id="soir" name="service" value="soir">
<label for="soir">Soir</label>

Le même name relie les boutons : un seul peut être coché. checked coche « Midi » par défaut.

3.32 — type="checkbox"

Plusieurs options peuvent être choisies en même temps.

<input type="____" id="terrasse" name="options" value="terrasse">
<label for="terrasse">Terrasse</label>
Voir la correction 
<input type="checkbox" id="terrasse" name="options" value="terrasse">
<label for="terrasse">Terrasse</label>

Les cases à cocher permettent plusieurs choix ; le label se place après la case.

3.33 — <fieldset> et <legend>

Regroupez les boutons radio sous le titre « Service ».

<____>
  <____>Service</____>
  <input type="radio" id="midi" name="service" value="midi">
  <label for="midi">Midi</label>
</____>
Voir la correction 
<fieldset>
  <legend>Service</legend>
  <input type="radio" id="midi" name="service" value="midi">
  <label for="midi">Midi</label>
</fieldset>

<fieldset> regroupe, <legend> donne le titre du groupe, lu par les lecteurs d'écran.

3.34 — <textarea>

Créez un champ de message sur 4 lignes.

<label for="message">Votre message</label>
<____ id="message" name="message" ____="4"></____>
Voir la correction 
<label for="message">Votre message</label>
<textarea id="message" name="message" rows="4"></textarea>

<textarea> est une balise par paire, fermée immédiatement ; rows = nombre de lignes visibles.

3.35 — <select> et <option>

Créez une liste déroulante avec « Information » et « Réservation » (choisie par défaut).

<label for="sujet">Sujet</label>
<____ id="sujet" name="sujet">
  <____ value="info">Information</____>
  <____ value="reservation" ____>Réservation</____>
</____>
Voir la correction 
<label for="sujet">Sujet</label>
<select id="sujet" name="sujet">
  <option value="info">Information</option>
  <option value="reservation" selected>Réservation</option>
</select>

Le texte de l'<option> est affiché, sa value est envoyée. selected choisit l'option par défaut.

3.36 — <button>

Ce bouton doit envoyer le formulaire.

<button type="____">Envoyer</button>
Voir la correction 
<button type="submit">Envoyer</button>

submit envoie, reset vide les champs, button ne fait rien sans JavaScript.

Séance 4 — Révision et projets 1 et 2

8 exercices sur la séance 4 : la seule balise nouvelle (<figure>) et les chemins d'un site de plusieurs pages, utiles pour le Projet 2.

Les images légendées

4.1 — <figure> et <figcaption>

Regroupez la photo et sa légende « La crêpe nature, notre classique ».

<____>
  <img src="images/crepes.jpg" alt="Une pile de crêpes dorées">
  <____>La crêpe nature, notre classique</____>
</____>
Voir la correction 
<figure>
  <img src="images/crepes.jpg" alt="Une pile de crêpes dorées">
  <figcaption>La crêpe nature, notre classique</figcaption>
</figure>

<figure> regroupe l'image et sa légende ; <figcaption> contient la légende, à l'intérieur du <figure>.

4.2 — La place de <figcaption>

Ce code contient une erreur : la légende n'est pas reliée à l'image. Corrigez-la.

<figure>
  <img src="images/terrasse.jpg" alt="La terrasse et ses tables en bois">
</figure>
<figcaption>Ouverte de mai à septembre</figcaption>
Voir la correction 
<figure>
  <img src="images/terrasse.jpg" alt="La terrasse et ses tables en bois">
  <figcaption>Ouverte de mai à septembre</figcaption>
</figure>

<figcaption> doit être à l'intérieur du <figure>, en premier ou en dernier. En dehors, elle ne légende rien.

4.3 — Légende ou alt ?

Le alt répète la légende. Réécrivez-le pour qu'il décrive ce que montre la photo.

<figure>
  <img src="images/chef.jpg" alt="Notre chef depuis 2010">
  <figcaption>Notre chef depuis 2010</figcaption>
</figure>
Voir la correction 
<figure>
  <img src="images/chef.jpg" alt="Un cuisinier en tablier retourne une crêpe dans une poêle">
  <figcaption>Notre chef depuis 2010</figcaption>
</figure>

Le alt décrit l'image pour qui ne la voit pas ; la légende ajoute une information, visible par tout le monde. Ne mettez pas le même texte dans les deux.

Les chemins entre les pages

4.4 — De l'accueil vers une page

Dans projet-2/index.html, le bouton « Réserver une table » doit mener à projet-2/pages/contact.html.

<a href="____">Réserver une table</a>
Voir la correction 
<a href="pages/contact.html">Réserver une table</a>

Depuis index.html, on descend dans le dossier pages/, puis on nomme le fichier.

4.5 — D'une page vers l'accueil

Dans projet-2/pages/contact.html, le lien « Accueil » doit mener à projet-2/index.html.

<a href="____">Accueil</a>
Voir la correction 
<a href="../index.html">Accueil</a>

contact.html est rangé un dossier plus bas : ../ remonte d'un niveau, jusqu'à projet-2/.

4.6 — Entre deux pages voisines

Dans projet-2/pages/galerie.html, le lien « Infos pratiques » doit mener à projet-2/pages/infos.html.

<a href="____">Infos pratiques</a>
Voir la correction 
<a href="infos.html">Infos pratiques</a>

Les deux pages sont dans le même dossier pages/ : le nom du fichier suffit. pages/infos.html chercherait un dossier pages/pages/.

4.7 — Une image depuis pages/

Dans projet-2/pages/galerie.html, affichez l'image projet-2/images/salle.jpg.

<img src="____" alt="La salle du restaurant, vue depuis l'entrée">
Voir la correction 
<img src="../images/salle.jpg" alt="La salle du restaurant, vue depuis l'entrée">

On remonte d'abord dans projet-2/ avec ../, puis on descend dans images/.

4.8 — Le menu et la page en cours

Ce menu est celui de pages/galerie.html. Complétez les chemins, et marquez le lien de la page en cours avec la classe actif.

<nav>
  <ul>
    <li><a href="____">Accueil</a></li>
    <li><a href="galerie.html" ____>Galerie</a></li>
    <li><a href="____">Infos</a></li>
    <li><a href="____">Contact</a></li>
  </ul>
</nav>
Voir la correction 
<nav>
  <ul>
    <li><a href="../index.html">Accueil</a></li>
    <li><a href="galerie.html" class="actif">Galerie</a></li>
    <li><a href="infos.html">Infos</a></li>
    <li><a href="contact.html">Contact</a></li>
  </ul>
</nav>

Le menu est le même sur les 4 pages, mais ses chemins changent selon l'endroit où se trouve la page. La classe actif passe d'un lien à l'autre : le CSS s'en servira.
