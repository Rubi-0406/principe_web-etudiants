Aide-mémoire HTML et CSS

Toutes les balises HTML vues dans les séances 1 à 4, puis le CSS des séances 5, 7 et 8 (sélecteurs, habillage, mise en page, responsive), rangés par thème. Pour chacun : son rôle en une ligne, la séance où il est expliqué, et un lien vers sa documentation complète sur MDN.

Comment l'utiliser

  • Cherchez une balise avec Ctrl + F.
  • La colonne Vu dans vous ramène directement à la section du cours qui l'explique (S1 = séance 1, etc.).
  • Le lien MDN ouvre la documentation de référence, en français, dans un nouvel onglet : exemples, attributs, compatibilité.

1. Le squelette et le <head>

Le squelette et le <head>
Balise / code Rôle en une ligne Vu dans Doc
<!DOCTYPE html> Déclare qu'il s'agit d'une page HTML5. Toujours en première ligne. S1 · Le squelette MDN
<html lang="fr"> La racine qui contient toute la page ; lang indique la langue. S1 · Le squelette MDN
<head> Les informations sur la page, invisibles dans la page. S1 · Le squelette MDN
<meta> Métadonnées : encodage (charset), viewport, description. S1 · Le squelette MDN
<title> Le titre affiché dans l'onglet, les favoris et les résultats de recherche. S1 · Le squelette MDN
<link rel="stylesheet"> Relie la page à une feuille de style CSS (la vôtre ou une bibliothèque). S1 · Le squelette MDN
<body> Tout le contenu visible de la page. S1 · Le squelette MDN
<!-- ... --> Un commentaire : une note dans le code, ignorée par le navigateur. S1 · Les commentaires MDN

2. Le texte

Le texte
Balise / code Rôle en une ligne Vu dans Doc
<h1> à <h6> Les six niveaux de titres : un seul <h1>, pas de saut de niveau. S1 · Titres et paragraphes
S2 · Titres		 MDN
<p> Un paragraphe de texte. S1 · Les balises
S2 · Paragraphes		 MDN
<br> Un retour à la ligne à l'intérieur d'un paragraphe (adresse, poème). S1 · Les balises MDN
<hr> Une rupture thématique entre deux parties du contenu. S1 · <hr> MDN
<strong> Importance forte : un avertissement, une information à ne pas manquer. S2 · L'emphase MDN
<em> Accent d'insistance : le mot sur lequel on appuierait à l'oral. S2 · L'emphase MDN
<b> Attire l'attention, sans notion d'importance (mot-clé). S2 · Autres balises MDN
<i> Un ton différent : mot étranger, terme technique, titre d'œuvre. S2 · Autres balises MDN
<u> Une annotation (faute d'orthographe signalée). À éviter : on le confond avec un lien. S2 · Autres balises MDN
<s> Un texte barré, qui n'est plus exact (ancien prix). S2 · Texte barré MDN
<blockquote> Une citation longue, en bloc (attribut cite pour la source). S2 · Citer et montrer du code MDN
<code> Un morceau de code dans le texte. S2 · Citer et montrer du code MDN
<pre> Un texte préformaté : garde les espaces et retours à la ligne (blocs de code). S2 · Citer et montrer du code MDN
&lt; &gt; &amp; &copy; Les entités, pour afficher les caractères réservés : < > & ©. S1 · Les entités HTML MDN

Les listes
